## O que construir

Entregar um tracer runtime nas URLs atuais que seleciona `legacy | assured` no composition root e preserva autenticação, idioma e CopilotKit/AG-UI. O modo `assured` consolida os tokens e componentes React/CSS próprios já existentes. No modo local, o shell exibe um indicador persistente e inequívoco sem mudar o contrato de API nem tornar o redesign o padrão.

## Stack e geração de código

- Frontend: Next.js e React com tokens e componentes próprios do Assured UI; não adicionar pacote, asset, fonte ou identidade visual da Rede D'Or.
- Backend não é alterado nesta fatia; não há geração RNF.

## Critérios de aceite (verificáveis)

- [x] `legacy` permanece o modo padrão e as mesmas URLs renderizam o composition root escolhido por configuração.
- [x] O modo `assured` carrega os estilos compartilhados antes das rotas e renderiza uma rota real sem erro de hidratação.
- [x] O indicador de ambiente local aparece em todas as páginas no shell Assured UI e não aparece como recurso materializado.
- [x] Autenticação, troca de idioma e uma conversa CopilotKit/AG-UI continuam alcançáveis no tracer.
- [x] O manifest e o lockfile não contêm dependências `@rededor/*`.

## Definition of done

```bash
cd apps/frontend && npm run lint
cd apps/frontend && npm run typecheck
cd apps/frontend && npm run check:i18n
cd apps/frontend && npm run build
```

## Decisões / notas

A ativação global fica reservada para F15. Nenhuma rota `/v2` ou preferência por usuário é criada. A revisão de 2026-09-01 substituiu CURA pelo Assured UI próprio do projeto.

- O seam fica no `AppShell`; MSAL, next-intl, CopilotKit e AG-UI permanecem nos providers existentes.
- `NEXT_PUBLIC_FRONTEND_MODE` aceita `legacy | assured` e mantém `legacy` como fallback; `NEXT_PUBLIC_DATA_MODE` aceita `connected | local` e mantém `connected` como fallback.
- O indicador local é exclusivo do shell `assured` e explicita que os recursos Azure ainda não foram materializados.
- Em telas estreitas, o shell `assured` usa drawer para manter navegação, tema e idioma acessíveis sem overflow; o shell `legacy` não foi alterado.
- Validação: verificador do contrato, lint, typecheck, i18n e build verdes; 96/96 gates backend verdes; inspeção Playwright desktop/móvel e rota `/d/helpdesk` com composer montado.
