## O que construir

Entregar a escolha entre Prompt Agent no Foundry, workflow declarativo executado por harness existente e agente com container próprio. O FormFlow deriva campos, regras e validações do documento e grava operações em um ChangeSet, sem componentes exclusivos por tipo nem alegar execução do workflow.

## Stack e geração de código

- Skill: `rnf-validation` — manter validações OKF no domínio Python e retorná-las com contexto editável.
- Frontend: escolha de rota, formulário declarativo e inspeção técnica acessível com o Assured UI.
- Justificativa RNF: a fatia estende módulos Python existentes; não há scaffolding RNF Node aplicável.

## Critérios de aceite (verificáveis)

- [ ] As três rotas geram somente envelopes, kinds e bindings admitidos pelo perfil OKF.
- [ ] Alterar um FormFlow válido altera os campos renderizados sem criar componente específico para o kind.
- [ ] Erros de schema, referência e autorização aparecem no campo ou documento correspondente e bloqueiam gravação inválida.
- [ ] A definição técnica permanece inspecionável e nenhum workflow é apresentado como executável por esta entrega.
- [ ] Author consegue salvar e retomar cada rota em SQLite pelo mesmo contrato HTTP.
