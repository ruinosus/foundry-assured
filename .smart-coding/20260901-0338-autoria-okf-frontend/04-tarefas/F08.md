## O que construir

Entregar catálogo, detalhe e editor de bundles com árvore de documentos, FormFlow, diff base-proposta, dependências e validações. Referências internas resolvem no ChangeSet, externas na fonte dona, e a submissão congelada nunca é sobrescrita.

## Stack e geração de código

- Skill: `rnf-validation` — validar grafo, referências, hashes e concorrência no domínio Python.
- Frontend: editor denso responsivo com navegação, diff e painéis sem cards aninhados no Assured UI.
- Justificativa RNF: a fatia usa contratos OKF/FormFlow existentes; não há gerador RNF compatível.

## Critérios de aceite (verificáveis)

- [ ] `/bundles`, `/bundles/[id]` e `/bundles/[id]/edit` preservam seleção e links profundos válidos.
- [ ] Árvore, documento ativo, diff, validações e dependências refletem a mesma revisão do ChangeSet.
- [ ] Referências internas e externas são resolvidas conforme suas fontes e lacunas impedem submissão quando bloqueadoras.
- [ ] Revisão concorrente retorna conflito e oferece rebase ou nova revisão sem sobrescrita.
- [ ] Versão submetida é imutável e edição posterior gera nova revisão.

## Definition of done

```bash
uv run --project apps/backend --no-sync python -m tests.okf.changeset_test
uv run --project apps/backend --no-sync python -m tests.okf.catalog_test
cd apps/frontend && npm run verify:text-diff
cd apps/frontend && npm run verify:okf
cd apps/frontend && npm run lint
cd apps/frontend && npm run typecheck
cd apps/frontend && npm run build
```

## Checklist NORDOR-122

- [ ] Consulta e edição exigem Reader/Author no tenant e área do bundle.
- [ ] Grafo, documentos, IDs e revisões possuem schema e limites.
- [ ] Conteúdo dinâmico e diff são protegidos contra injection/XSS.
- [ ] Logs registram IDs e hashes, sem conteúdo integral.
