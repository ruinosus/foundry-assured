## O que construir

Entregar catálogo, detalhe e editor de bundles com árvore de documentos, FormFlow, diff base-proposta, dependências e validações. Referências internas resolvem no ChangeSet, externas na fonte dona, e a submissão congelada nunca é sobrescrita.

## Stack e geração de código

- Skill: `rnf-validation` — validar grafo, referências, hashes e concorrência no domínio Python.
- Frontend: editor denso responsivo com navegação, diff e painéis sem cards aninhados no Assured UI.
- Justificativa RNF: a fatia usa contratos OKF/FormFlow existentes; não há gerador RNF compatível.

## Critérios de aceite (verificáveis)

- [x] `/bundles`, `/bundles/[id]` e `/bundles/[id]/edit` preservam seleção e links profundos válidos.
- [x] Árvore, documento ativo, diff, validações e dependências refletem a mesma revisão do ChangeSet.
- [x] Referências internas e externas são resolvidas conforme suas fontes e lacunas impedem submissão quando bloqueadoras.
- [x] Revisão concorrente retorna conflito e oferece rebase ou nova revisão sem sobrescrita.
- [x] Versão submetida é imutável e edição posterior gera nova revisão.

## Definition of done

```bash
uv run --project apps/backend --no-sync python -m tests.okf.changeset_test
```

## Checklist NORDOR-122

- [x] Consulta e edição exigem Reader/Author no tenant e área do bundle.
- [x] Grafo, documentos, IDs e revisões possuem schema e limites.
- [x] Conteúdo dinâmico e diff são protegidos contra injection/XSS.
- [x] Logs registram IDs e hashes, sem conteúdo integral.

## Decisões / notas

- Bundle é uma projeção especializada do `ChangeSetService`; documentos, FormFlows, policies, use cases e bindings permanecem no conteúdo versionado, sem tabela ou store paralelo.
- Revisões são append-only com CAS por ETag. `submit` congela a revisão corrente e uma edição posterior exige a transição explícita para uma nova revisão `draft`.
- Referências resolvem primeiro no conjunto de documentos da mesma revisão e depois no catálogo factual da fonte dona. Ausência falha; indisponibilidade fica pendente; ambos bloqueiam submissão.
- As escritas exigem `Author` sem concessão implícita a `Admin`; tenant e área continuam derivados pelo router de autoria.
- A interface Assured UI fixa revisão e documento na URL, usa o diff textual existente e oferece recarga/rebase após conflito sem sobrescrever a revisão concorrente.
