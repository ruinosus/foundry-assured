## O que construir

Fazer discovery de endpoint aprovado nos modos public, Foundry connection e OBO, mantendo toda
credencial em memória. O caminho oficial resolve connection/identidade e o mesmo canário prova que
segredo não chega a API, erros, telemetria, Table, Blob ou audit.

## Stack e geração de código

Backend Python existente e SDKs Microsoft verificados. RNF/CLI não se aplica à integração Python
com Foundry/Entra; usar `DefaultAzureCredential`, OBO e project connection pelas superfícies dos
módulos donos. Não criar broker ou secret store novo.

## Critérios de aceite

- [x] Public não envia header; connection é tenant-local; OBO usa o usuário da request e audience aprovada.
- [x] Token/credencial são resolvidos no momento da conexão e descartados após a operação.
- [x] Connection de outro tenant e auth incompatível falham fechados antes de `tools/list`.
- [x] Header sensível nunca segue redirect nem é passado como argumento de tool/framework.
- [x] Canary secret fica ausente de response, exception, log, span, Table, Blob e audit.
- [x] Storage usa `DefaultAzureCredential`, WORM e SSE; nenhum account key/SAS é introduzido.

## Checklist NORDOR-122

- [x] Menor privilégio por tenant, connection, OBO scope e papel.
- [x] Nenhum segredo hardcoded, persistido, incluído em fixture ou logado.
- [x] TLS em trânsito e Azure Storage SSE em repouso.
- [x] Telemetria protege URL/querystring, token, headers e identidade desnecessária.
- [x] Falhas de auth retornam código controlado sem detalhe do provedor.

## Decisões / notas

- `connectionRef` resolve primeiro a `Connection.id` do tenant atual e só então usa a referência Foundry.
- Foundry Connections são lidas pelo módulo `foundry` com `DefaultAzureCredential`; OBO usa a identidade da request e scope derivado do catálogo aprovado.
- O bearer é obtido pelo `header_provider` após abrir a operação, cacheado somente na closure da sessão e nunca projetado em resposta ou evidência.
- A origem aprovada deve corresponder ao endpoint oficial do tipo da Connection; falha de SDK ou auth vira `MCP_AUTH_NOT_AVAILABLE` sem detalhe interno.
