## O que construir

Comparar observações canônicas, quarentenar somente tools alteradas e exigir revisão Admin quando
o contrato ou a versão default mudar. Falha operacional preserva o último snapshot como histórico,
mas marca a source `stale` e bloqueia promoção/execução.

## Stack e geração de código

Backend Python existente. RNF/CLI não se aplica à lógica de assurance Python. Usar uma biblioteca
mantida de RFC 8785, após verificar versão/API, e `hashlib.sha256`; não escrever canonicalizador.

## Critérios de aceite

- [x] JCS RFC 8785 torna ordem de tools/chaves irrelevante e preserva ordem semântica de arrays.
- [x] Hash inclui descrição, input/output schemas e annotations permitidas; campos descartados não entram.
- [x] Adição, remoção, contrato e classificação aparecem no diff e bloqueiam somente a tool afetada.
- [x] Mudança de default/resolved version bloqueia promoção até review Admin completo.
- [x] Falha de auth/timeout/protocolo mantém snapshot anterior e projeta `stale` sem mutá-lo.
- [x] Pre-call conformity recusa stale/drift antes de qualquer request MCP.

## Definition of done

```bash
uv run --project apps/backend --no-sync python -m tests.platform_ops.mcp_canonical_hash_test
uv run --project apps/backend --no-sync python -m tests.platform_ops.mcp_drift_test
uv run --project apps/backend --no-sync python -m tests.platform_ops.mcp_stale_test
uv run --project apps/backend --no-sync python scripts/gates.py
```

## Checklist NORDOR-122

- [x] Review exige Admin e é uma decisão distinta das demais aprovações.
- [x] Snapshot/hash/id e payload de review passam por validação estrita.
- [x] Estado stale/drift falha fechado antes de rede.
- [x] Logs têm contagens e hashes, sem metadata remota ou dado sensível.

## Decisões e notas de execução

- O hash canônico reutiliza o saneamento único da discovery e aplica RFC 8785 antes do SHA-256.
- A projeção mutável guarda somente identidade da source, hashes, contagens e estado operacional; o snapshot continua imutável no Blob.
- Snapshot legado sem projeção mantém compatibilidade; source conhecida com `stale` ou drift falha fechado antes da rede.
- Review promove apenas o snapshot mais recente, exige classificação completa e usa CAS por revisão.
