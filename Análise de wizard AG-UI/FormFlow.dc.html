O componente não conhece campo nenhum

Não existe aplicar() com if p.field === "instructions": o setter é derivado do id declarado. Trocar de manifesto troca o wizard inteiro, inclusive os campos que o copiloto pode escrever.

A proposta é validada antes de virar decisão

Peça um name ao agente: a proposta chega com maiúsculas, bate na mesma regra do campo e Usar fica desabilitado com o motivo. Hoje isso só apareceria na publicação.

Um gate, quatro lugares

A mesma política cobre proposta de campo, operação de publicação, tool de escrita do agente e escalação do workflow: papel exigido, payload exibido, recusa com motivo, lote. Publique a skill e a base para ver plano com dependência e falha parcial.
