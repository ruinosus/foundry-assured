Os campos de um copiloto

Identidade, superfície (onde monta e em quais telas), motor, fundamentação, alvos (qual formflow e quais campos dele ele escreve), tools de escrita com papel, HITL herdado, medição, tom e plano de publicação. Nada de prompt solto: o prompt é derivado destes campos.

Parser, não framework

O agente lê o bundle e despacha por type. Três tipos bastam: copilot, formflow, policy. Um quarto tipo amanhã é um parser novo, não um produto novo — e bundles de terceiros já entram porque o formato é vendor-neutral.

O que continua sendo código

Os tipos de campo e os gates. Declarar um campo novo é dado; inventar um controle novo é código, com escape hatch registrado no manifesto. É a linha que impede o manifesto de virar uma linguagem de programação pela porta dos fundos.
