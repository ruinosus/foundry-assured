A regra que organiza tudo

O produto guarda referência + contrato, nunca o código da peça. Por isso trocar a implementação de um middleware não é mexer no copiloto: ele cita um nome, e o nome resolve no registry.

Onde não há desenvolvimento

Bundle é texto: nasce no editor daqui ou num PR. Adaptador é conexão: identidade, região, cota. MCP de fornecedor já existe — você registra a URL. Esses três não pedem uma linha de código.

Onde há, e é pouco

Middleware é uma função com contrato. Agente próprio é um serviço que fala AG-UI. MCP interno é um servidor com tools. Nos três, o scaffold já vem com o manifesto e o teste — o trabalho é a lógica, não a integração.
